# Local Skill Loop Context

## Canonical terms

- **Local Loop Template**: Git-tracked, sanitized files that define repeatable local experiment mechanics.
- **Local Loop Instance**: the ignored `.agents/skill-loop/` directory created for one linked worktree.
- **Round Snapshot**: ignored, immutable records for one execution round: manifest, validation, artifacts, and review.
- **Case Executor**: an isolated agent that analyzes one private case using only the current Skill and its required references.

Private JD text, reports, scores, and user reviews are not part of this template.
