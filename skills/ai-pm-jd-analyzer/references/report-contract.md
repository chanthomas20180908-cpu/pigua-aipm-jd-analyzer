# 默认报告契约

使用以下 Markdown 章节，内容以 JD 证据为准：

1. `# AI PM JD 分析`：给出一句话结论和约 120–200 字的口语化总结。
2. `## 事实与推断边界`：分别列出明确事实、谨慎推断和无法确认的信息。
3. `## 岗位与价值流`：说明岗位上下文；用表格展示价值流、目的和按顺序排列的工作事项。
4. `## 工作事项、实体与能力`：逐项写明工作目的、相关实体及 CRUD、所需能力和原文证据。
5. `## 岗位判断`：列出 2–4 条工作重点、2–4 条亮点、2–4 条风险，以及 3–6 条关键发现。
6. `## 最需确认的三件事`：写三条会改变岗位判断的信息缺口或风险确认项。
7. `## 面试追问`：给出 2–4 条针对具体缺口、职责边界、指标或技术要求的问题。

结论保持友好、克制且可行动；不要评分、攻击招聘方或把推断写成事实。
