# 完整元模型默认报告契约

按以下顺序使用 Markdown 输出：

1. `# AI PM JD 完整元模型分析`：一句话结论和约 120–200 字口语化总结。
2. `## 事实、推断与未披露边界`：分别列出 `explicit`、`inferred`、`not_disclosed` 的关键项。
3. `## 公司与岗位画像`：公司上下文、岗位画像和薪酬福利；未披露待遇明确写出，不虚构范围。
4. `## 价值流、事项与角色责任`：价值流顺序表、事项、RACI 责任与证据。
5. `## 实体、能力与关系`：事项 CRUD、实体唯一主归属能力、实体关系与能力依赖。实体表必须展示业务描述、JD 支持的属性及其证据状态；能力表必须展示业务描述、主归属实体和支撑事项。
6. `## 任职要求与工作环境`：要求类别、必要程度、映射状态，以及环境对事项/要求的影响。
7. `## 风险、待确认与岗位判断`：事实异常、谨慎推断、2–4 条风险、最需确认三件事和 2–4 条面试追问。
8. `## 结构化模型 JSON`：紧跟一个且仅一个 `json` fenced code block；内容严格符合 `full-model-schema.json` 的 `ai_pm_jd_full_model/v2` 契约，不得在代码块内加入注释、Markdown 或省略号。

报告使用短表格和项目列表，所有关键结论标注证据状态。风险保持克制：未映射要求首先是待确认项，JD 未披露不等于负面事实。
