# capabilities 目录说明

## 目的
保留 v2/v3 规则与能力模块，供旧接口兼容和历史逻辑参考。

## 定义
旧版能力模块目录，不是当前 v4 主链路的扩展入口。

## 范围包括
- JD 分析、候选人分析、匹配评分、推荐和叙事等旧版能力函数。
- v3 兼容能力模块。

## 范围不包括
- 不承载 v4 SubModule prompt、schema 或工作流配置。
- 不新增面向当前主链路的业务能力。

## 使用与修改规则
- 除兼容修复外尽量不改；新判断逻辑应进入 app/sub_modules/library.py。
- 修改旧接口行为时必须确认 /analyze 或 /analyze/v3 的兼容影响。
