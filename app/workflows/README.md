# workflows 目录说明

## 目的
承载分析流程编排，把请求输入转换为按模块累积的分析上下文。

## 定义
工作流层，负责调用能力模块或 SubModule，但不直接定义 prompt 资产。

## 范围包括
- v4 JD 分析主链路。
- 保留兼容的 v2/v3 job fit 工作流。

## 范围不包括
- 不放 FastAPI 路由、不放前端展示逻辑、不放测试数据。

## 使用与修改规则
- 当前维护重点是 analyze_jd_v4.py。
- 改动 context key 或返回结构时同步后续子模块 prompt 和前端渲染。
