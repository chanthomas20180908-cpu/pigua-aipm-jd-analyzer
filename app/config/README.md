# config 目录说明

## 目的
集中放置后端工作流的显式配置，让编排顺序和模块选择可被快速定位。

## 定义
配置包，目前主要定义 v4 三大模块管道和子模块版本。

## 范围包括
- workflow_v4.py 中的模块分组、执行顺序和模块版本配置。

## 范围不包括
- 不写 LLM prompt 正文、不写业务执行逻辑、不写前端配置。

## 使用与修改规则
- 新增/替换子模块时先确认 SUB_MODULE_LIBRARY 中存在对应 (name, version)。
- 配置变更需要同步 app/workflows/analyze_jd_v4.py 的读取假设。
