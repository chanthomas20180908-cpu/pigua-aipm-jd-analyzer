# assets 目录说明

## 目的
承载前端页面使用的静态素材集合。

## 定义
前端资源子目录，用于图片、动效帧和其他非代码展示资产。

## 范围包括
- 按主题或品牌拆分的素材子目录。

## 范围不包括
- 不放业务 JS/CSS，不放临时生成素材源文件。

## 使用与修改规则
- 新增素材要放入清晰命名的子目录，并在子目录 README 说明来源和替换规则。
