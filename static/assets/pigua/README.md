# pigua 素材目录说明

## 目的
提供“劈瓜”前端 loading 动画使用的本地帧图片。

## 定义
品牌/吉祥物素材目录，当前由 design-preview-02.js 按序播放 PNG 帧。

## 范围包括
- frame-01.png 到 frame-05.png 及素材说明。

## 范围不包括
- 不放与劈瓜动画无关的图片，不在图片里写死业务文案。

## 使用与修改规则
- 替换图片时保持文件名或同步修改 MASCOT_FRAMES。
- 推荐透明背景 PNG，并保留加载失败占位逻辑。

## 既有内容

# 劈瓜帧动画素材

`design-preview-01.html` 会读取以下图片作为卡皮巴拉劈瓜帧动画：

- `frame-01.png`
- `frame-02.png`
- `frame-03.png`
- `frame-04.png`
- `frame-05.png`

当前内置素材来自 `tmp/imagegen_frames/640x480/`，尺寸为 `640x480`。

后续替换建议：

- 使用透明背景 PNG。
- 推荐尺寸为 `800x600` 或 `640x480`。
- 图片只画卡皮巴拉和瓜，不要把对白画死在图里。
- 当前 loading 动画只播放图片序列，不叠加对话框。

素材缺失或加载失败时，页面会显示占位卡片，不影响三步交互主流程。
